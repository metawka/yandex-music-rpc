<h1 align="center">Yandex Music RPC</h1>

<p align="center">Статус «Слушает» в Discord для десктопной Яндекс Музыки. Как у Spotify, только для Яндекса.</p>

В профиле видно трек, исполнителя, обложку и полоску прогресса. Название трека, имя артиста и обложка кликабельные и ведут в Яндекс Музыку. Поставили трек на паузу, статус пропал. Включили снова, вернулся.

Программа весит меньше мегабайта, сидит в трее и почти не ест ресурсы. Клиент Яндекс Музыки она не трогает: ничего не патчит, не лезет в `app.asar`, не просит логин и токен. После обновления Яндекс Музыки всё продолжает работать.

## Установка

Скачайте последний релиз со страницы [Releases](https://github.com/metawka/yandex-music-rpc/releases/latest):

- `YandexMusicRPC-Setup.exe` ставит программу, добавляет в автозапуск и в список установленных приложений. Права администратора не нужны.
- `YandexMusicRPC.exe` портативная версия. Запустили, и она работает. Автозапуск включается в меню трея.

Нужны Windows 10 или 11, десктопная Яндекс Музыка и приложение Discord. Браузерная версия Discord не подойдёт, к ней программы подключаться не умеют.

Если статус не появился, проверьте в Discord: Настройки → Конфиденциальность активности → «Показывать текущую активность» должно быть включено.

## Меню в трее

Правый клик по значку в трее показывает, что сейчас играет и подключён ли Discord. Там же включается и выключается запуск вместе с Windows. Других настроек нет: статус выглядит так же, как у Spotify.

У статуса две кнопки: «Слушать трек» и «RPC на GitHub». В своём профиле вы их не увидите, Discord показывает кнопки только другим людям.

## Как это устроено

Яндекс Музыка сама сообщает Windows, что играет: название, исполнителя, позицию в треке. Это та же информация, которую Windows показывает в плашке громкости. Программа берёт её оттуда, ищет трек через открытый поиск Яндекс Музыки, чтобы получить обложку и ссылки, и передаёт всё в Discord через его локальный канал для Rich Presence.

Наружу уходит только поисковый запрос «исполнитель + название» на `api.music.yandex.net`. Больше программа никуда не ходит.

Если что-то не работает, приложите к issue файл `%APPDATA%\YandexMusicRPC\log.txt`.

## Сборка

Нужен Rust (toolchain `stable-x86_64-pc-windows-msvc`).

```bash
cargo build --release
```

Готовый файл появится в `target\release\yandex-music-rpc.exe`. Установщик собирается [Inno Setup 6](https://jrsoftware.org/isinfo.php):

```bash
iscc installer\setup.iss
```
