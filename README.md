<h1 align="center">Yandex Music RPC</h1>

<p align="center">Discord Rich Presence для десктопного приложения Яндекс Музыки под Windows.</p>

## Возможности

- Статус «Слушает Яндекс Музыка» в профиле Discord: название трека, исполнитель, альбом, обложка и шкала прогресса.
- Ссылки на трек, исполнителя и альбом в Яндекс Музыке.
- Кнопки «Слушать трек» и «RPC на GitHub».
- Статус скрывается, когда воспроизведение на паузе или приложение закрыто.
- Работает из системного трея, запуск вместе с Windows включается в меню.
- Клиент Яндекс Музыки не модифицируется, авторизация и токены не требуются.

## Требования

- Windows 10 или 11.
- Десктопное приложение Яндекс Музыки.
- Десктопное приложение Discord. Веб-версия Discord не поддерживается.

## Установка

Загрузите файл со страницы [последнего релиза](https://github.com/metawka/yandex-music-rpc/releases/latest):

- `YandexMusicRPC-Setup.exe` устанавливает программу для текущего пользователя, добавляет её в автозагрузку и в список установленных приложений. Права администратора не требуются.
- `YandexMusicRPC.exe` портативная версия, установка не требуется.

## Использование

После запуска программа работает в фоне. Меню вызывается правым кликом по значку в трее и содержит:

- текущий трек;
- состояние подключения к Discord;
- переключатель «Запускать вместе с Windows»;
- ссылку на страницу проекта и выход.

Для отображения статуса в Discord должен быть включён параметр «Настройки → Конфиденциальность активности → Показывать текущую активность».

Кнопки в карточке статуса видны другим пользователям. В собственном профиле Discord их не показывает.

## Принцип работы

Яндекс Музыка передаёт в Windows сведения о воспроизведении: название, исполнителя и позицию трека. Программа считывает их через системный интерфейс управления медиа, находит трек через публичный поиск Яндекс Музыки для получения обложки и ссылок и передаёт статус в Discord через локальный IPC.

Единственный сетевой запрос программы: поиск по строке «исполнитель + название» на `api.music.yandex.net`.

Журнал работы сохраняется в `%APPDATA%\YandexMusicRPC\log.txt`.

## Сборка

Требуется Rust с toolchain `stable-x86_64-pc-windows-msvc`.

```bash
cargo build --release
```

Исполняемый файл: `target\release\yandex-music-rpc.exe`. Установщик собирается с помощью [Inno Setup 6](https://jrsoftware.org/isinfo.php):

```bash
iscc installer\setup.iss
```
